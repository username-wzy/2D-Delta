## 接入与维护

- [assets.js](../js/assets.js)统一描述图集和 ID 映射；DOM 使用 CSS 背景取样，Canvas 使用 drawImage 取样。图像保持原始长宽比。
- 新图集经过独立主体边界裁切、居中等格重排，保留生成像素及 alpha，避免相邻格串图；没有重新绘制、抠色或添加背景。
- 前四张图集沿用已验证的透明间隙取样。特工原图不带枪，战局叠加实际持有武器。
- 物品使用定义 ID 或地面实例 type 查图；历史 emoji 字段仅作为旧存档数据保留，任何显示路径均不使用。
- 图像未加载或未知 ID 使用中性线框轮廓，Canvas 使用相同用途的几何后备图；不阻止部署。
- 新增物品占格、稀有度、护甲耐久与维修参数保存在 client/data/loot.json，商店相同 ID 同步对应元数据。图像尺寸不决定物品占格。
- 完整预览：[asset-preview.html](../asset-preview.html)。场景墙体、树木、撤离点和投掷手雷均已改为图像渲染。
