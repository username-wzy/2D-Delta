## 接入与维护

- [assets.js](../js/assets.js) 统一描述图集和 ID 映射；DOM 使用 CSS 背景取样，Canvas 使用 `drawImage` 取样。
- 生成内容并非严格落在均匀网格内。映射中针对特工行间、P90/SVD 之间、钥匙卡与文件柜/衣柜之间的透明间隙调整了区域，避免图像被截断或混入相邻物品。DOM 与 Canvas 均保持图像比例。
- 特工原图不带枪，战局单独叠加当前武器；敌人使用各自的完整图像。碰撞、射击判定、装备参数和存档格式沿用原有规则。
- 小尺寸图标增加枪型、恢复量、护甲等级及钥匙卡颜色标签。HUD 图标未变化时保留现有 DOM 节点。
- 不把图像路径写进旧存档：从配置 ID 或地面物品 `type` 查找图像。原 `emoji` 字段同时保留为加载失败回退。
- 继续保留树木、墙体、撤离标记、贵重品和界面提示中的 Emoji。新增图像只替换明确需要区分的实体。
- 替换图集时同步更新实际尺寸与取样区域，并检查透明通道和邻格串图。生成提示词、资产预览和浏览器检查应一并更新。
