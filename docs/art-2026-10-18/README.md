[完整提示词与裁切记录](prompts.json)保存原始生成提示、输入输出尺寸、原图裁切和目标坐标、SHA-256。原始输出保留在 [sources](sources)目录。生成时明确要求 alpha 背景、独立主体、军用手绘材质、无文字和水印。

生成模型并不严格遵守等格留白，因此接入前仅进行机械处理：在指定格内找主体边界、裁切原有像素、等比例缩小并居中放入等格透明画布。没有重绘主体、修改配色、抠色或填充背景。处理后逐张检查了维修包、工业物资、树木与撤离点；图集格线保持透明。

## 渲染规则

- DOM 与 Canvas 共用 assets.js 映射和同一 PNG 裁切区域。
- 墙体、树木、撤离标记、手雷与全部物资改为图片；界面文字与后备图不再显示 Emoji。
- 图集加载失败显示中性线框箱体，角色显示简化人形，场景显示几何障碍；后备图不影响实际碰撞或交互。
- 战局按视口裁掉屏幕外物品/墙体绘制，并以稀有度色环标记物资。
