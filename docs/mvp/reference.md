## 机制对照

| 官方所述概念 | 本项目的单机转译与验收方向 |
|---|---|
| 带装备进入、搜刮后撤离；阵亡会损失未受保护的携带物品 | 装备在部署时预留，撤离与死亡各结算一次；仓库和局内物品保持明确边界 |
| 保险箱可保护少量物品 | 采用 2×2 格保护栏表达风险管理；保护规则、可放物品与阵亡结果必须直接展示 |
| 售卖搜索所得换取主要货币；补给站提供备战物品 | 战利品先入仓，再出售；购买、扣款、入仓与保存合为一次事务 |
| 配装区与存储区分开 | 大厅保留可辨识的角色与武器，装备、仓库和商店各有清晰区域 |
| 物品采用灰、绿、蓝、紫、金、红六类稀有度；弹药和护甲有等级 | 稀有度用颜色及文字共同表达，避免只依靠颜色识别；不把物品稀有度当作子弹伤害 |
| 生命伤害、护甲耐久与穿透相互作用 | 玩家和 Bot 共用同一伤害函数；耐久耗尽后不能继续产生无限减伤 |
| 不同损伤使用对应医疗用品，治疗期间需要谨慎选择位置 | MVP 先明确医疗恢复量与使用时长，再扩展损伤；不能把尚未实现的骨折/流血显示为已支持 |
| 固定、条件、开关、随机和付费等撤离点 | MVP 选固定与付费两类；费用与余额在开始计时前可见，成功结算时同一事务扣费 |
| 枪声与脚步暴露位置 | Bot 只调查观察或声音产生的位置；丢失视线后保留最后已知位置，不隔墙读取实时坐标 |

表中官方事实来自上述官方新手引导与地图工具；右栏为 2D 实现选择，并非原作完整规则表。房间、队伍、市场与真实玩家对战不属于当前单机流程。

## 精确数值与能力边界

本次没有核实可直接照搬到当前 2D 比例的官方冲刺消耗/恢复阈值、恢复等待时间、各枪像素射程、手雷引信和爆炸半径、统一撤离倒计时、治疗时长或售卖比例。

项目中的这些数值属于本地平衡参数，必须通过配置、说明和回归保持一致。特别是 2D 像素不能直接当作官方世界距离，付费撤离的费用和 10 秒默认倒计时也不能描述为原作统一数值。官方新手引导包含特定武器、弹药、护甲组合的算例，不把该算例推广成所有等级及版本的完整伤害公式。

MVP 的治疗、保护栏、付费撤离与伤害机制应逐项记录实测行为；本对照文档本身不构成已完成这些功能的证据。

## 本轮 MVP 的本地规则方案

以下均为本项目的单机平衡选择，完成状态需由主流程和体验验收记录确认：

- 角色基础生命 100；职业不赠送高级护甲，护甲等级和耐久由实际装备决定。对敌我双方使用同一简化伤害函数。
- 保险箱为 2×2 格，物品需要显式放入；未保护携带物品在阵亡或行动失败时遗失。
- 行动上限为 10 分钟；固定/付费撤离显示各自计时与条件。当前默认撤离读条 10 秒，工厂付费出口费用 3,000，均可通过地图元数据调整。
- 药品使用读条；手雷具有飞行过程、引信与碰撞。治疗时长、引信秒数、射程、爆炸半径和消耗/恢复率以项目配置与回归为准。
- Bot 保留视线锥、最后已知位置、声音调查和反应时间。树木与墙体均阻挡实体移动，个别武器射线规则通过共享物理函数定义。

这些数字与简化方式不能称作已经复刻官方精确机制。当前阶段不加入联机房间或账号认证。
