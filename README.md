# 🦅 Emoji Delta

使用 HTML5 Canvas 绘制的俯视角 2D 搜打撤游戏。角色、枪械和关键装备采用手绘图像，场景、贵重品和提示保留 Unicode Emoji。选择特工、整理装备、搜索战利品并对抗 Bot，在撤离区存活 10 秒后带走物资。

## 当前版本

| 部分 | 当前状态 |
|---|---|
| 浏览器游戏 | 单机本地模拟，原生 JavaScript ES Modules，已提供大厅、商店、仓库、战斗、搜索和结算 |
| C# 服务端 | 独立运行的 .NET 8 WebSocket 服务器，包含固定 60Hz Tick、输入校验、战局状态和玩家事件队列 |
| 多人联机 | 尚未接入浏览器客户端；地图统一、房间、快照、预测和输入重放待实现 |
| 档案与资产 | 单个本地档案，金币、仓库和装备使用 localStorage 保存；服务端账号认证与数据库待实现 |

项目协作与架构约定见 [AGENT.md](AGENT.md)，多人计划见 [多人游戏需求文档](docs/多人游戏需求文档.md)。

## 美术资产

当前包含 4 张透明 PNG 图集，共 37 项：6 名特工、7 类敌人、8 把枪，以及 16 件装备和搜索容器。枪械通过轮廓和型号区分，弹药、药品、护甲及三色钥匙卡也使用独立图像。大厅选人、商店、仓库、HUD、背包、拾取列表和战局共用相同的资产映射；角色手持武器随切枪更新。

树木、墙体、撤离标记、现金、钻石、首饰及操作提示继续使用 Emoji。图像在后台预加载，未加载或加载失败时回退到原 Emoji；原存档无需迁移。

启动下方的本地 HTTP 服务后，可从大厅底部进入 [美术资产预览](client/asset-preview.html)。[资产说明](client/assets/README.md) 包含图集路径和完整生成提示词；[接入与验证记录](docs/assets-2026-10-17/接入与验证.md) 包含截图、浏览器检查与复现命令。

## 快速开始

游戏需要现代浏览器和 Python 3；前端无需安装 npm 依赖或进行构建。运行 C# 服务端需要支持 `net8.0` 的 .NET SDK、目标框架包和运行时；客户端回归需要 Node.js。

以下命令均在项目根目录执行：

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

打开 [游戏页面](http://127.0.0.1:8080/client/) 或 [地图编辑器](http://127.0.0.1:8080/tools/map-editor.html)。如果系统的 Python 命令是 `python3`，替换命令中的 `python`。游戏通过 HTTP 加载 JSON 配置，需要用上述地址访问。

浏览器单机游戏可以独立运行。需要开发或检查服务端时，在另一个终端执行：

```powershell
dotnet run --project server/EmojiDelta.Server.csproj
```

服务端监听 `http://localhost:5000/`，用于 WebSocket 通信。启动它不会自动让浏览器进入多人模式。两个终端中的服务均可使用 Ctrl+C 停止。

## 开始一次行动

1. 输入特工代号进入本地档案，新档案有 $50,000 金币。
2. 选择特工和地图，在商店购买物品。点击仓库物品切换选中状态，可多选后批量装备或出售；点击已装备物品可卸下。
3. 确认携带容量后部署。未携带购买的武器时使用特工默认武器。
4. 搜索容器、拾取物资并击败 Bot，前往撤离区域保持存活 10 秒。
5. 撤离后返回大厅，新增战利品进入仓库，可以继续出售或装备。

## 操作

| 按键 | 功能 |
|---|---|
| W / A / S / D | 移动 |
| Shift | 冲刺，消耗体力 |
| 鼠标移动 / 左键 | 瞄准 / 开火 |
| R | 换弹 |
| 1 / 2 | 切换携带武器 |
| F | 拾取、搜索或打开容器 |
| Tab | 展开或收起局内背包 |

快捷键仅在行动中生效，输入框不会触发游戏操作；失焦或页面隐藏时清空持续输入。自动武器可按住开火，M870 和 SVD 每次按下射击一次。

## 玩法规则

### 搜索与拾取

- 靠近容器按 F 搜索，保持静止直至完成；移动会中断并清空搜索进度。文件柜和衣柜默认需要 3 秒，保险柜需要 5 秒及对应的红、蓝或绿钥匙卡，钥匙不消耗。
- 搜索完成后通过容器面板逐件或全部拾取。离开交互范围、隔墙或行动结束后不能继续从面板取物。
- 地上遗落背包需要先搜索 1.5 秒，完成后生成 2～3 件物品；反复按 F 或点击 H 列表不能跳过搜索。
- H 列表展示 250px 内物品，拾取时检查距离和视线；遗落背包仍需靠近搜索。
- 战利品来自容器和 Bot 击杀掉落。6 位特工、8 把武器、7 种 Bot、26 种战利品和 19 种商店商品通过 JSON 配置。

### 装备、药品与弹药

- 最多携带两把枪、一件护甲和一个背包；贵重品只能存放或出售。
- 特工基础容量为 8～16 格，装备一个战术背包增加 4 格；大厅即时显示容量，超容量时需卸下物品才能部署。
- 药品拾取后存入背包，不自动回血。按 4 自动选择合适药品，或点击背包中的具体药品；医疗包、外科手术包和注射器分别恢复 50、100、30 HP，使用会消耗该物品。
- 拾取的手雷计入可用库存，按 G 投掷会消耗一个。
- 弹药箱按配置补充对应类型的共享备弹，可供两把匹配的枪使用；已打开的弹药箱不会保留为可出售物品。各武器独立保存弹匣、冷却和换弹进度，切枪后换弹继续。
- 医生脱离伤害 3 秒后每秒恢复 2 HP，狙击手散布乘 0.3，工程师搜索耗时减半。

### 撤离与本地保存

进入撤离区域后倒计时 10 秒，受击重置计时，离开区域取消撤离。若最后一帧受到致命伤，按阵亡处理。

成功撤离恢复未消耗的带入装备，把新增战利品存入仓库，并发放一次 $5,000 奖励。战利品出售价格为其保存价值的 40%，撤离时不会再把物品价值直接加到金币中。例如从初始 $50,000 带出价值 $35,000 的蓝钻，撤离后有 $55,000，出售蓝钻获得 $14,000，余额为 $69,000。

阵亡会失去携带装备和战利品，原有仓库物品保留。行动中刷新或关闭页面视为放弃，携带装备遗失；结算保存失败时需保留原页面，检查浏览器存储后点击“重试保存”。

本地档案保存在当前浏览器的站点存储中，不同浏览器或协议、主机、端口之间不会自动同步。用户名和本地密码属于单个本地档案，服务端账号认证尚未实现。

## 地图编辑与配置

默认工厂地图位于 [client/maps/factory_01.json](client/maps/factory_01.json)，为 50×38 图块，包含 18 个容器和 3 个撤离区域。运行上述 HTTP 服务后可访问 [地图编辑器](http://127.0.0.1:8080/tools/map-editor.html)：

1. 设置名称、尺寸及图块大小，绘制地形。图块 0 表示空地，1 表示墙，2 表示树木。
2. 至少放置一个位于空地的 PMC 出生点及一个地图范围内的撤离区域；容器也需位于空地，保险柜可选择钥匙颜色。
3. 导出 JSON，在游戏大厅点击“导入地图 JSON”选择文件，确认地图出现在下拉列表后部署。

导入文件不得超过 4 MB，地图加载时检查尺寸、图块、出生点、容器和撤离范围。导入地图只保留在本次页面会话中；游戏按地图实际宽高和图块大小进行移动及渲染。

配置入口：

| 文件 | 内容 |
|---|---|
| [operators.json](client/data/operators.json) | 特工属性、容量、被动和默认武器引用 |
| [weapons.json](client/data/weapons.json) | 武器参数、射击模式和弹药类型 |
| [bots.json](client/data/bots.json) | Bot 属性、攻击方式和生成权重 |
| [loot.json](client/data/loot.json) | 战利品价值、效果和掉落权重 |
| [shop.json](client/data/shop.json) | 商店商品与价格 |

在项目根目录运行：

```powershell
node --experimental-vm-modules docs/fixes-2026-10-02/client-regression.cjs
dotnet build server/EmojiDelta.Server.csproj
dotnet run --project docs/fixes-2026-10-02/server-regression.csproj
```

也可用 PowerShell 脚本完成客户端回归、服务端还原、构建和回归：

```powershell
./docs/fixes-2026-10-02/verify.ps1
```

当前开发机器已有 .NET 8.0.20 引用包缓存，需要复用该缓存时执行：

```powershell
./docs/fixes-2026-10-02/verify.ps1 -UseCachedNet8References
```

该选项针对本机缓存，不更改项目的 `net8.0` 目标框架；其他机器通常使用普通还原与构建。

2026-10-02 的修复验证结果为客户端 17/17 组、服务端 12/12 组通过，服务端构建 0 警告、0 错误。客户端回归执行真实模块，DOM、存储、音效和绘制等使用替身；服务端回归使用真实处理器、固定 Tick、事件队列和内存 WebSocket，不启动 HTTP 监听。浏览器多人联机尚未接通。
